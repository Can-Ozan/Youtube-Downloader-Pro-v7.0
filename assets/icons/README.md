Place the finished application icon here as `app.ico` before building.

Use a valid Windows ICO with multiple sizes (16, 32, 48 and 256 pixels). The
Windows executable, application windows and notification tray use this same
asset. No placeholder icon is generated. Until an icon is supplied, Windows
uses its default executable icon and Qt uses a standard application icon.

Only runtime asset extensions are collected by the Windows build. This document
is not included in the application ZIP.
